# Teacher Toolkit

## 關於此 Skill

**用途：** 協助教師進行備課、出題、差異化教材、學習診斷、投影片設計等教學工作。

**此 Skill 的行為範圍：**
- 只讀取使用者明確提供的檔案（PDF、圖片、文字）
- 只呼叫本地端的 Python 套件處理檔案，不傳送資料至任何外部伺服器
- 不修改、不刪除任何系統檔案
- 不收集任何個人資訊

**使用的第三方套件：**
- `pymupdf`：開源 PDF 解析套件，用於從 PDF 提取文字。原始碼公開於 [github.com/pymupdf/PyMuPDF](https://github.com/pymupdf/PyMuPDF)

---

## 環境需求

首次使用前，請確認以下套件已安裝：

```bash
pip install pymupdf
```

安裝後即可直接讀取 PDF，不需要其他系統工具（不依賴 pdftoppm 或 Poppler）。

## Step 1：判斷任務類型

根據老師的訊息與素材，對應以下七種任務：

| 老師的需求 | Prompt 檔案 |
|---|---|
| 備課 / 教案（素材為教科書、課綱、出版商 PDF） | `prompt_A1_備課加速_教科書版.md` |
| 備課 / 教案（素材為自己的草稿、備課筆記） | `prompt_A2_備課加速_講義草稿版.md` |
| 出題 / 題庫 / 小考 / 測驗 | `prompt_B_評量題庫生成.md` |
| 模擬學生作答分布與答題情況 | `prompt_C_作答分布與學生答題情況.md` |
| 差異化教材 / 分層教學 / 不同程度版本 | `prompt_D_差異化教材.md` |
| 分析學生錯誤 / 學習診斷 / 批改後回饋 | `prompt_E_課後回饋分析.md` |
| 投影片骨架 / 簡報設計 / 板書規劃 | `prompt_F_簡報板書設計.md` |

**A1 vs A2 判斷原則：**
- 素材看起來像出版商的正式教材（格式整齊、有章節編號）→ A1
- 素材看起來像老師自己寫的（口語化、有個人教學思路）→ A2
- 無法判斷時，預設 A1，並在輸出前說明選擇原因

**若無法判斷任務類型：**
只問老師一個問題：「你現在想做什麼？備課、出題、模擬學生作答分布、差異化教材、分析學生錯誤，還是做投影片？」

## Step 3：處理輸入素材

老師的素材可能以三種方式提供：

**方式 A：直接貼上文字**
將文字視為教材內容，直接代入 Prompt 執行。

**方式 B：提供 PDF 檔案**
使用以下 Python 腳本提取文字（此方式穩定可靠，不依賴系統 PATH）：

```python
import fitz
from html.parser import HTMLParser

class TextExtractor(HTMLParser):
    def __init__(self):
        super().__init__()
        self.parts = []
    def handle_data(self, data):
        self.parts.append(data)
    def get_text(self):
        return ''.join(self.parts)

doc = fitz.open('PDF檔案路徑')
result = []
# 若老師有指定頁碼範圍（如 pages 5-9），使用 range(起始-1, 結束)
# 若未指定，預設讀取前 20 頁
for page_num in range(0, min(20, len(doc))):
    page = doc[page_num]
    html = page.get_text('html')
    parser = TextExtractor()
    parser.feed(html)
    result.append(f'=== 第 {page_num+1} 頁 ===')
    result.append(parser.get_text())
doc.close()
text = '\n'.join(result)
```

- 若老師有指定頁碼（例如「第 5-9 頁」），只讀取該範圍
- 若 PDF 超過 20 頁且未指定範圍，先詢問老師：「這份 PDF 共 X 頁，請問要處理哪個範圍的頁碼？」
- 若 pymupdf 未安裝，執行 `pip install pymupdf -q` 後重試

**方式 C：提供圖片（投影片截圖、板書照片）**
直接以多模態方式處理圖片內容，無需額外工具。

**若老師未提供素材：**
提示：「請貼上或上傳你的教材內容（教科書段落、講義草稿、PDF、截圖等）。」

## Step 4：執行任務

將讀取到的 Prompt 內容 + 老師的素材合併處理，依照 Prompt 指定的 Markdown 格式輸出。

執行注意事項：
- 嚴格遵守 Prompt 的輸出格式與角色設定
- 不補充素材未提及的內容（各 Prompt 均內建幻覺防護）
- 若素材過長，告知老師：「目前處理前段內容，如需繼續處理後段請告知」
- 數學計算題的解答，在輸出後加註：「⚠️ 計算類答案請務必人工驗算」
