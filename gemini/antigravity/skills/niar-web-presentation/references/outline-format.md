# Outline Format

Create `outline.md` before building unless the user already supplied a clear slide/reveal plan.

## Minimal Structure

```markdown
# <Presentation Title>

Audience:
Purpose:
Playback mode: live / recording-friendly / both
Source files:

## Slide 01 - <Title>
- Background: cover-gradient-wave-logo.png
- Goal:
- NIAR signals: background, logo, kicker, navy panel, orange rule
- Reveals:
  0. <initial state>
  1. <first reveal>
  2. <second reveal>
- Visual notes:
- Source / evidence:

## Slide 02 - <Title>
...
```

## Slide Fields

- `Background`: choose a bundled background PNG.
- `Goal`: one sentence explaining what the slide should accomplish.
- `NIAR signals`: list the brand signals used.
- `Reveals`: each reveal is a step in the slide. Keep reveals purposeful.
- `Visual notes`: layout, motion anchor, chart/table/photo notes.
- `Source / evidence`: source file, section, evidence row, or `inference`.

## Reveal Count Guidance

- Cover: 1-3 reveals.
- Standard content slide: 2-4 reveals.
- Table/data slide: 2-5 reveals.
- Timeline/process: 3-6 reveals.
- Closing: 1-3 reveals.

Do not force a fixed number of slides. Choose slide count by content and audience.

## Content Density

- One slide may contain several elements, but do not show them all at once.
- Keep each reveal readable by itself.
- Split a slide if a reveal becomes a dense paragraph.
